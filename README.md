# Orbital Reverb (VST3 / AU) — by Dante Ramos

Reverb con Planet (Moon, Mercury, Jupiter, Black Hole), Size, Pre-delay, Tone, Decay, Mix, Output, Bypass y estilo Galaxy / Neón.

## Cómo compilarlo
1. Crea un repositorio nuevo en GitHub y sube TODO el contenido de esta carpeta (incluida la carpeta oculta `.github`).
2. Pestaña **Actions**: la compilación arranca sola (10-15 min).
3. Descarga el artefacto **OrbitalReverb-windows-latest** (o macos).
4. Copia `Orbital Reverb.vst3` a `C:\Program Files\Common Files\VST3\` (Mac: `/Library/Audio/Plug-Ins/VST3/`).
5. En Cubase: Studio > VST Plug-in Manager > Rescan. Aparece en Reverb como "Orbital Reverb".
